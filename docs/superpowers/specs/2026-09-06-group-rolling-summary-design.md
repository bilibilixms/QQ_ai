# QQ 群共享上下文与滚动摘要设计

## 目标

为每个 QQ 群增加共享上下文，使机器人能够理解连续讨论，同时将每次普通回复的输入控制在固定预算内。上下文不按用户拆分，群内成员共享同一份记忆。该功能继续独立于 DSH，仅依赖当前 OneBot 服务和 DeepSeek API。

## 范围

本次改造包含：

- 每群保存一条滚动摘要。
- 每群保存最近若干条原始消息。
- 请求前估算输入 token，接近预算时先执行摘要压缩。
- 普通回复使用“系统提示词 + 群摘要 + 最近消息 + 当前触发内容”。
- 摘要失败时保留现有消息窗口并继续尝试普通回复；普通回复失败时不推进已读状态。
- 修复管理员关键词命令路径中的 `seq` 变量错误。
- 关键词管理命令仅允许群主执行，群管理员无权限。

不包含：用户级独立记忆、管理后台、向量数据库、自动话题分类和跨群记忆。

## 权限

机器人管理权限仅授予 OneBot 事件中 `sender.role` 为 `owner` 的群主。群管理员（`admin`）和普通成员均不能修改、删除或查看管理配置；本次最小范围内，唯一受此限制的命令是 `!关键词 添加`、`!关键词 删除` 与 `!关键词 列表`。

## 数据模型

扩展 `groups` 表：

- `summary TEXT NOT NULL DEFAULT ''`：群共享摘要。
- `summary_updated_at INTEGER`：最近一次摘要更新时间。

继续使用现有 `messages` 表和 `last_read_seq` 游标。消息成功处理后推进游标；摘要压缩成功后，只删除已经纳入摘要的旧消息，保留最近窗口。

## 配置

新增环境变量：

- `CONTEXT_TOKEN_BUDGET=3000`：摘要、消息和当前请求的输入预算。
- `RECENT_MESSAGE_LIMIT=10`：普通请求最多携带的最近原始消息条数。
- `SUMMARY_MAX_CHARS=1200`：摘要字符上限，防止摘要自身无限增长。
- `SUMMARY_TRIGGER_RATIO=0.85`：估算输入达到预算 85% 时触发压缩。
- `SUMMARY_KEEP_MESSAGES=6`：压缩完成后保留的最新原始消息数。

token 估算采用保守字符换算，不引入额外 tokenizer 依赖：中文和其他文本按约 1.5 字符/token 估算，并为消息角色和格式保留少量余量。预算不是服务端硬限制，而是本地压缩触发阈值。

## 请求流程

1. 保存群消息并识别管理员命令。
2. 非触发消息只入库，不调用模型。
3. 触发消息到来时读取群摘要和最近消息窗口。
4. 若估算输入达到 `CONTEXT_TOKEN_BUDGET * SUMMARY_TRIGGER_RATIO`，调用一次摘要请求：
   - 输入：旧摘要 + 较早原始消息。
   - 输出：新的短摘要，限制在 `SUMMARY_MAX_CHARS` 内。
5. 摘要成功后写回 `groups.summary`，删除已压缩的旧消息，保留 `SUMMARY_KEEP_MESSAGES` 条最新消息。
6. 使用最新摘要、最近消息和当前触发内容发起普通 DeepSeek 请求。
7. 普通回复成功并发送到群后，推进 `last_read_seq`；失败则保留游标，便于下次重试。

摘要请求与普通回复使用同一个 DeepSeek 模型配置，但通过独立的内部提示词要求只输出事实、结论、未解决问题和必要上下文，不输出闲聊或元解释。

## 失败与并发处理

- 摘要请求失败：记录错误，跳过压缩，使用现有窗口继续普通请求；若普通请求也失败，发送现有兜底消息。
- 摘要结果为空或超长：视为失败，不覆盖旧摘要。
- 普通请求失败：不推进游标，不删除消息。
- 单个 WebSocket 连接按顺序处理事件，避免同群游标竞争；后续多连接场景需要增加数据库锁或群级异步队列。
- 当前版本不自动删除已读历史消息，只有摘要压缩成功时才清理已纳入摘要的旧消息。

## 成本预期

普通请求输入近似固定为：系统提示词 + 摘要（约 600 token 上限）+ 最近消息窗口 + 当前触发内容。摘要请求每达到预算才发生一次，成本均摊到多个群消息上。与无限累积历史相比，总输入 token 会明显下降；与完全无上下文相比，会增加摘要和窗口成本，但获得连续对话能力。

## 测试

至少覆盖：

- 新群初始化摘要为空。
- 未达到阈值时不调用摘要接口。
- 达到阈值时摘要成功、写回并保留指定数量的最新消息。
- 摘要失败时旧摘要和消息仍可用于普通请求。
- 普通请求成功后游标推进，失败后游标不推进。
- @触发、关键词触发行为不变。
- 仅群主可执行 `!关键词` 命令；群管理员和普通成员不能执行。
- `!关键词` 命令不再引用未定义的 `seq`。
